Data Pipeline

Alur komunikasi yang digunakan oleh dashboard ini.

M12FTH3Q → USB/Modbus RTU → Raspberry Pi → MQTT TCP/1883 → broker.emqx.io → MQTT over WSS/8084 → Web Dashboard.

Koneksi ke broker saja tidak berarti sensor aktif. Status sensor akan berubah setelah paket valid diterima.

Prototipe edukasi: broker MQTT ini bersifat publik. Jangan kirim kredensial, data sensitif, atau perintah aktuator. Riwayat grafik tersimpan hanya pada browser yang sedang digunakan.
